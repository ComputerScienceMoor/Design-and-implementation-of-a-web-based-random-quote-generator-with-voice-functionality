# Design-and-implementation-of-a-web-based-random-quote-generator-with-voice-functionality
By Folowosele Samuel Ayomide  (NDCOM/24/665)
Random Quote Generator with Voice is a web-based application designed to provide users with an easy and interactive way to discover quotations. The system uses the API Ninjas Quotes API to generate random quotes based on selected categories.

The application allows users to search, generate, copy, share, and save favourite quotes. It also includes Text-to-Speech functionality, allowing users to listen to quotations through their device. Other features include user authentication, speech controls, light/dark mode, and a responsive interface for computers, tablets, and smartphones.

The project was developed using HTML5, CSS3, JavaScript, PHP, MySQL, and API Ninjas, with XAMPP used as the local development environment.
